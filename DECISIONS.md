# Технические решения

- Основной сценарий — локальное обнаружение и диагностика Bluetooth LE без Home Assistant для этапа исследования.
- Для BY Smart A60 не подтверждён прикладной протокол управления. Никакие произвольные Tuya-пакеты не отправляются.
- Приложение показывает найденные BLE-устройства, позволяет подключиться к выбранному устройству и перечисляет GATT-службы/характеристики и свойства.
- Существующий Home Assistant-контроллер пока оставлен как резервный режим, чтобы не ломать уже реализованный аудиоконвейер.
- Следующий этап после теста на реальной лампе: сопоставить GATT UUID и обмен Smart Life, определить процедуру аутентификации/шифрования и только затем реализовать RGB-команды.
